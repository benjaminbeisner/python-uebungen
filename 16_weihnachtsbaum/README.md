# Weihnachtsbaum · Christmas tree

🇩🇪 Zeichnet einen Weihnachtsbaum aus Sternchen in der eingegebenen Höhe und Breite. Falsche Eingaben werden abgefangen, am Ende gibt es ein Protokoll aller Bäume.

🇬🇧 Draws a Christmas tree of asterisks with the given height and width. Invalid input is caught, and a log of all trees is printed at the end.

# Kreditkarten-Prüfziffer · Credit card check digit

🇩🇪 Berechnet für eine 16-stellige Kartennummer die Prüfziffer nach dem Luhn-Algorithmus und vergleicht sie mit der letzten Ziffer. Ohne Eingabe wird eine Beispielnummer verwendet.

🇬🇧 Calculates the Luhn check digit of a 16-digit card number and compares it with the last digit. Without input, a sample number is used.

# Passwortgenerator · Password generator

🇩🇪 Erzeugt ein zufälliges 8-stelliges Passwort aus druckbaren ASCII-Zeichen und prüft, ob Groß- und Kleinbuchstabe, Zahl und Sonderzeichen enthalten sind. Ist das nicht der Fall, kann ein neues erzeugt werden.

🇬🇧 Generates a random 8-character password from printable ASCII characters and checks that it contains an uppercase and a lowercase letter, a digit and a special character. If not, a new one can be generated.

*März 2026 · March 2026*

```bash
python main.py
```

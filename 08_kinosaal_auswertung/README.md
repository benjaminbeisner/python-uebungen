# Kinosaal-Auswertung · Cinema analysis

🇩🇪 Ein Kinosaal ist als 2D-Liste gespeichert (Alter der Besucher, 0 = frei). Das Programm zählt die belegten Plätze, berechnet das Durchschnittsalter, findet die vollste Reihe und listet die Plätze von Besuchern unter 21.

🇬🇧 A cinema is stored as a 2D list (visitor ages, 0 = empty). The program counts occupied seats, calculates the average age, finds the fullest row and lists the seats of visitors under 21.

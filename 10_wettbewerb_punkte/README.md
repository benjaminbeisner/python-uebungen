# Punktewertung im unfairen Wettbewerb · Scoring an unfair competition

🇩🇪 Vier Teilnehmer haben Punkte in vier Kategorien. Das Programm berechnet Gesamtpunkte, den Sieger, den Durchschnitt je Kategorie und entfernt alle unter 25 Punkten aus einer Kopie der Liste.

🇬🇧 Four participants have scores in four categories. The program calculates totals, the winner, the average per category and removes everyone below 25 points from a copy of the list.

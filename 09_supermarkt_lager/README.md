# Lager eines chaotischen Supermarkts · Chaotic supermarket warehouse

🇩🇪 Die Regale sind als 2D-Liste gespeichert. Das Programm summiert alle Produkte, findet das vollste Regal, setzt Bestände unter 5 auf 0 (einmal in einer Kopie, einmal im Original) und meldet leere Plätze.

🇬🇧 The shelves are stored as a 2D list. The program sums all products, finds the fullest shelf, sets stock below 5 to 0 (once in a copy, once in place) and reports empty slots.

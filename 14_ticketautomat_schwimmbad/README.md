# Ticketautomat Schwimmbad · Swimming pool ticket machine

🇩🇪 Projektaufgabe: Ein Automat verkauft Kurzzeit-, Langzeit- und Tagestickets, berechnet Wechselgeld aus seinem Kassenbestand, gibt Abonnenten einen Sonderpreis, berechnet einen Sauna-Zuschlag und begrenzt die Gültigkeit auf die Schließzeit 22 Uhr. Sechs Unit-Tests prüfen die Logik.

🇬🇧 Project task: a machine sells short, long and day tickets, gives change from its cash stock, offers subscribers a special price, adds a sauna surcharge and limits validity to the 10 pm closing time. Six unit tests check the logic.
